# OpenClassrooms Web Development Project 3 by Diego Jorge
Project name: "Integrate a mobile website with animations in CSS"

https://arcadine.github.io/Project-3/index.html

# Project Objectives:
"This project involves working on the mobile-first interface of a start-up's website. You'll implement CSS animations using SASS and version your project using Git and GitHub. Your main task will be to integrate a mobile-first model. You'll be provided with mockups for mobile and desktop, the prototype on Figma, and the necessary images and texts. This mobile-first approach will help you understand the importance of designing responsive, adaptive websites. You'll learn how to implement CSS animations to enrich the site's user experience. These animations will bring the interface to life, making navigation more interactive and engaging. Finally, you'll version your project with Git and GitHub, familiarizing yourself with these essential tools for managing and collaborating on web development projects."
